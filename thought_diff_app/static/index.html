Thought Diff

Local app. Not published to an extension marketplace.

Readings are recomputed from the Python AST as the working copy changes. Not regeneration, and not recovered model thoughts.

What the readings are, and what is skipped

The app re-reads the working copy when it changes. It does not call a model and does not rewrite code on its own. Interpretations are deterministic AST readings of the code as it is now, not recovered thoughts of the model that wrote it. Not regeneration.

Structure and line readings are computed for Python files. Other text files are included in the code diff and read as plain text. The frozen original is never written.
